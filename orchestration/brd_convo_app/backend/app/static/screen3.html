How to use the Blueprint Document Template Editor

Getting started

1

Fill in the Client Context

At the top of the editor, enter the client's company name, industry, ERP system, planning maturity, pain points, and Phase 1 scope. This context is automatically injected into every prompt so the generated content is specific to your client - not generic.

These fields are saved automatically and persist across page refreshes.
2

Pick a section from the left panel

Click any section in the left sidebar to load it. Sections are grouped by number (1-6). Use the search box at the top of the sidebar to jump quickly - type a section number like 3.2 or a keyword like demand and press Enter.

Color dots show status: grey = not started, amber = in progress, green = generated.
3

Review and edit keywords

Each section has two keyword tag lists pre-loaded from your prompt config files:

Web search keywords - sent to the /web_search endpoint to fetch live web context.

Document search keywords - used for BM25 retrieval from your uploaded reference documents via /doc_search.

Add tags by typing and pressing Enter. Remove tags by clicking x.

More specific keywords = more relevant generated content.
4

Regenerate the prompt

After editing keywords, click Regenerate prompt from keywords. This rebuilds the generation prompt using your updated keyword sets and displays it in the Prompt Preview box. The client context from Step 1 is automatically appended.

5

Optionally edit the prompt directly

The Prompt Preview textarea is fully editable. You can manually add extra instructions, client-specific notes, or constraints before generating. Whatever text is in that box at generation time is what the agent receives.

6

Changes are auto-saved

Every keyword edit, prompt change, and client context update is automatically saved 800ms after you stop typing. You will see a small "Saving..." indicator in the top bar while it saves, and "Saved" when complete. No manual save needed.

7

Generate the section

Click Generate section to run the agent for the current section only. The output appears in the Generated Output box at the bottom. The section dot turns green when done.

Click Generate full Blueprint Document to run all 32 sections sequentially - use this only after tuning keywords for all sections.

Start with Section 2 (Benefit Realization) - it has the richest default keyword set.

Tips

Recommended first run

Fill in the Client Context fields -> open Section 2 -> add 2-3 industry-specific web keywords -> click Regenerate prompt -> review the prompt -> click Generate section. This gives you a baseline output to evaluate quality before running the full Blueprint Document.

Press Esc or click outside this panel to close.
